# Wang Zhiwen Portfolio

Public display website. This repository contains website code and display exports only.
Original media, source documents, project files and editor backups must not be uploaded.

Images are resized, re-encoded and stripped of metadata. Videos are web encodes, not
original camera or production files. Full video duration is retained intentionally.
These public display copies can be downloaded by visitors; they are not DRM protected.

Publish main / (root) with GitHub Pages. The editor remains a client-side UI lock;
its changes are local to the current browser and do not change the repository.

Generate future releases from the local allowlist builder, never by uploading the
original media directory or the old repository history.
